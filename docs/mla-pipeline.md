# MLA Pipeline — Profile Analysis → Formation Suggestions

Sujet 4 besoin: **analyse des profils pour suggestions des formations**.

## Architecture

```text
Angular Improvement Plan
        → Spring Boot (LearnerIntelligenceService)
                → Python ml-service POST /suggest   (MLA)
                → fallback: Java rule-based ranking if ML down
```

## Dataset

- File: `ml-service/data/formations_suggestions.csv`
- ~1000 synthetic rows aligned to the platform catalogue (skills, levels, categories)
- Each row = learner profile + formation + label (`1` good suggestion / `0` poor)
- Generated by: `python scripts/generate_dataset.py`

No external Kaggle dataset — domain-specific data for a clear defense story.

## Pipeline steps

1. **Generate** dataset from catalogue seeds  
2. **Clean / features**: skill overlap, missing skills, level distance, goal match, same level  
3. **Train** RandomForestClassifier (`scripts/train.py`)  
4. **Evaluate** accuracy / F1 (see `models/metrics.json`)  
5. **Serve** FastAPI `/suggest`  
6. **Integrate** Spring Improvement Plan calls ML, keeps UI unchanged  

## Run locally

```bash
cd ml-service
source .venv/bin/activate
python scripts/generate_dataset.py   # if CSV missing
python scripts/train.py
uvicorn app.main:app --port 8000
```

Spring (`application.yml`):

```yaml
app:
  ml:
    enabled: true
    base-url: http://127.0.0.1:8000
```

Demo: login as learner → **Improvement plan** — reasons include `(MLA)`.

## Defense one-liner

> We built a synthetic labelled dataset of profile–formation pairs, engineered profile-analysis features, trained a RandomForest model, exposed it as a Python microservice, and Spring uses it to suggest formations.
